# Amaranth 10 이용가이드 점검 대시보드

구글 시트에 기록된 "Amaranth 10 이용가이드"(구 이용가이드 사이트) 정상 작동 점검 로그를 시각화한 정적 웹 대시보드입니다.

## 프로젝트 목표
- 담당자가 수동/CMD로 수행하는 사이트 정상 작동 점검 결과(로그인, 홈 화면 콘텐츠 표출 여부)를 한눈에 모니터링
- **당월 탭**과 **기간별 탭**을 구분하여 상황에 맞는 점검 현황을 조회
- 구글 시트 원본 데이터를 별도 백엔드 없이 브라우저에서 직접 조회하여 최신 상태 유지

## 데이터 출처
- Google Sheets: `https://docs.google.com/spreadsheets/d/132r740wkRSzKtyRe1LKomEZ-2jmdVJmFDBDHYY_PPxc/edit?gid=0#gid=0`
- 시트 컬럼 구조: `기간(날짜)`, `시간`, `방법(수동/수동(CMD))`, `상태(정상/오류 발생)`, `내용`, `성공률(100%/0%)`
- 대시보드는 Google Visualization API(`gviz/tq`)를 통해 CSV/JSON을 실시간 조회합니다. 시트가 "링크가 있는 모든 사용자에게 공개(보기 권한)"로 설정되어 있어야 정상적으로 연동됩니다.
- 네트워크 오류 등으로 시트 조회에 실패하면, 코드 내에 내장된 폴백(캐시) 데이터로 자동 전환되어 대시보드가 항상 표시됩니다.

## 완료된 기능
1. **헤더 영역**
   - 대시보드 타이틀("Amaranth 10 이용가이드 점검 대시보드"), 연결 상태 배지(실시간 연동됨 / 오프라인 캐시), 마지막 갱신 시각, 새로고침 버튼, 원본 시트 바로가기 링크, 인쇄/PDF 다운로드 버튼
2. **당월 / 기간별 탭 전환**
   - **당월 탭**: 최근 점검 상태, 당월 점검 총 건수, 정상 건수, 오류 건수, 성공률을 카드형 KPI로 표시(이미지 시안 반영)
     - 시작일/종료일 기본값은 **대한민국 표준시(KST, UTC+9) 기준 이번 달 1일 ~ 오늘**로 자동 설정되며, 사용자가 직접 날짜를 수정하여 "조회" 버튼으로 원하는 기간을 조회할 수 있습니다. "이번 달로 초기화" 버튼으로 언제든 기본값(이번 달 1일 ~ 오늘)으로 되돌릴 수 있습니다.
   - **기간별 탭**: 시작일/종료일 date picker로 원하는 기간을 조회, 조회/초기화 버튼 제공
     - 최초 진입 시 기본값이 **KST 기준 올해 1월 1일 ~ 오늘**로 자동 설정됩니다.
     - "올해 1월 ~ 오늘" 버튼으로 언제든 기본 범위로 재설정 가능하며, 사용자가 직접 다른 기간을 선택해 조회할 수도 있습니다.
   - 각 탭에 따라 KPI, 상태 비율 차트, 오류 이력, 로그 테이블이 해당 범위 데이터로 자동 갱신
   - 날짜 계산은 브라우저의 로컬 타임존과 무관하게 `Intl.DateTimeFormat`(timeZone: `Asia/Seoul`)을 이용해 항상 한국 시간 기준으로 처리됩니다.
3. **KPI 요약 카드**
   - 당월: 최근 점검 상태, 당월 총 건수, 정상 건수, 오류 건수, 성공률(5종 카드)
   - 기간별: 총 점검 횟수, 정상 건수, 오류 발생 건수, 평균 성공률(진행바), 최근 상태, 점검 방법(6종 카드)
4. **상태 비율 차트 (Chart.js 도넛)**
   - 선택된 탭(당월/기간별) 기준 정상·오류 비율 시각화
5. **오류 발생 이력 하이라이트**
   - 당월/기간별 탭에 관계없이 항상 노출되며, 제목이 "당월 오류 발생 이력" / "기간별 오류 발생 이력"으로 자동 전환됩니다.
   - 선택된 범위 내 오류 발생 건수를 배지로 표시(오류 0건이면 초록 배지 + "발생한 오류가 없습니다" 안내, 1건 이상이면 빨강 배지 + 오류 건별 카드(일시, 방법, 메시지)를 최신순으로 표시)
6. **점검 로그 테이블**
   - 선택된 탭(당월/기간별) 범위의 로그만 표시, 제목이 탭에 따라 자동 전환("당월 점검 로그" / "기간별 점검 로그")
   - 검색(내용/날짜/시간), 상태 필터, 방법 필터
   - 페이지네이션(페이지당 10건), 최신순 정렬
   - 정상/오류 상태 배지 색상 구분
7. **반응형 디자인**
   - Tailwind CSS 기반, 모바일/태블릿/데스크톱 레이아웃 대응
8. **로딩 처리**
   - 초기 데이터 로드 시 스피너 오버레이 표시, 새로고침 버튼으로 즉시 재조회 가능
9. **인쇄 / PDF 다운로드**
   - 헤더의 "원본 시트" 버튼 우측에 위치한 "인쇄/PDF" 버튼 클릭 시 브라우저 기본 인쇄 기능(`window.print()`)이 실행됩니다.
   - 인쇄 시에는 탭 버튼, 날짜 입력/조회 버튼, 검색/필터, 페이지네이션 등 조작용 UI 요소(`.no-print` 클래스 적용 영역)는 자동으로 숨겨지고, KPI 카드·차트·오류 이력·로그 테이블 등 데이터 콘텐츠만 출력되도록 `@media print` 스타일이 적용되어 있습니다.
   - 브라우저의 "PDF로 저장" 인쇄 대상을 선택하면 별도 서버 처리 없이 PDF 파일로 저장할 수 있습니다.

## 기능 엔트리 (파일/경로)
- `index.html` — 대시보드 단일 페이지 (모든 HTML/CSS/JS 포함)
  - 별도 URL 파라미터 없음 (단일 화면 대시보드)
  - 내부 상수 `SHEET_ID`, `GID` 를 통해 조회할 구글 시트 및 탭(gid) 지정
  - 조회 엔드포인트: `https://docs.google.com/spreadsheets/d/{SHEET_ID}/gviz/tq?tqx=out:json&gid={GID}`

## 데이터 모델
프론트엔드에서 파싱 후 사용하는 레코드 구조 (별도 DB 테이블 없이 클라이언트 메모리에서만 사용):
```js
{
  date: "2026-06-24",     // 기간
  time: "16:21:31",       // 시간
  method: "수동",          // 점검 방법 (수동 / 수동(CMD))
  status: "정상",          // 상태 (정상 / 오류 발생)
  content: "정상 로그인 및 홈 화면 콘텐츠(매뉴얼 업데이트 내역) 표출 확인 완료",
  rate: "100%"             // 성공률
}
```
- 저장소: 별도 데이터베이스 없음. 구글 시트가 원본(Source of Truth) 역할을 하며, 브라우저가 매 로드/새로고침 시 실시간 조회합니다.
- RESTful Table API는 사용하지 않았습니다(요구사항상 구글 시트 연동이 핵심이므로 시트를 직접 조회).

## 아직 구현되지 않은 기능 / 제한 사항
- 구글 시트 변경 시 자동 실시간 반영(웹소켓/자동 폴링)은 없으며, 사용자가 "새로고침" 버튼을 눌러야 최신 데이터를 다시 불러옵니다(단, 새로고침 시 당월/기간 범위는 그대로 유지되며 시트의 최신 값만 재조회됩니다).
- 시트 접근 권한이 "비공개"로 설정된 경우 브라우저에서 직접 조회가 불가능합니다(CORS/인증 필요 → 정적 사이트에서 처리 불가). 이 경우 폴백 데이터가 표시됩니다.
- CSV 다운로드, 알림(오류 발생 시 이메일/슬랙 알림) 기능은 포함되어 있지 않습니다.
- 인쇄/PDF 기능은 브라우저 내장 인쇄 기능(`window.print()`)을 활용한 것으로, 별도의 서버 사이드 PDF 생성이나 파일 다운로드 엔드포인트는 존재하지 않습니다(정적 사이트 제약).
- 데이터 컬럼이 늘어나거나(G열 이후) 구조가 바뀔 경우 파싱 로직(`loadSheetData` 함수)의 컬럼 인덱스를 수정해야 합니다.
- 날짜별 점검 현황 막대그래프, 성공률 추이 라인차트, 점검 방법 분포 파이차트는 사용자 요청에 따라 제거되었습니다(상태 비율 도넛 차트만 유지).

## 추천 다음 단계
1. 시트 공유 설정을 "링크가 있는 모든 사용자 - 뷰어"로 유지하여 실시간 연동이 끊기지 않도록 관리
2. 자동 폴링(예: 5분 주기 `setInterval`)을 추가해 새로고침 없이 최신 데이터 반영
3. 날짜 범위 선택 필터 및 CSV/이미지 내보내기 기능 추가
4. 오류 발생 시 브라우저 알림 또는 Webhook 연동(단, 인증 없는 공개 Webhook에 한해 가능)
5. 다크 모드 지원 추가

## 기술 스택
- HTML5 / CSS3 (Tailwind CSS via CDN)
- Vanilla JavaScript (ES6+)
- Chart.js 4.x (차트 시각화)
- Font Awesome 6 (아이콘)
- Google Visualization API(gviz)를 통한 Google Sheets 데이터 조회

## 배포
배포(퍼블리시)는 Genspark의 **Publish 탭**에서 원클릭으로 진행할 수 있습니다. Publish 탭에서 배포를 진행하면 실제 접속 가능한 라이브 URL이 발급됩니다.
